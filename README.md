# Equipment Desk — home-screen page

The icon and name for the Equipment Desk on the supervisors' phones.

The app itself is the Google Apps Script web app in
[Hyginix/hyginix-equipment-system](https://github.com/Hyginix/hyginix-equipment-system).
Apps Script can't give iOS a home-screen icon, so this page carries the icon and
shows the real app full screen inside a frame. It holds no data and no logic.

- Live: https://hyginix.github.io/equipment-desk/
- Sandbox: https://hyginix.github.io/equipment-desk/?test

Install on an iPhone: open the live link in **Safari** → Share → **Add to Home Screen**.
